# DRL drag reduction in turbulent channel flow — SAC + OpenFOAM

Code for the MSc thesis *Deep Reinforcement Learning for Turbulent Channel
Flow Drag Reduction* (Aditya Patil, Linköping University, 2026).
A soft actor–critic (SAC) agent, trained with Stable-Baselines3, controls
blowing and suction at the wall of a turbulent half channel (Re_tau = 180)
simulated with OpenFOAM. The OpenFOAM boundary condition `channelDRLControl`
and the base DNS case were provided by the supervisor (S. Salehi) and are
used unchanged; everything in `framework/` and `analysis/` was written in
this thesis.

## Layout

    framework/            SAC–OpenFOAM coupling (Python)
      environment.py        OpenFOAM environment: runs pimpleFoam episodes,
                            reads ActionState.dat and wall friction, builds reward
      training.py           SAC training loop (SB3), checkpointing, episode logs
      configs/channel.yaml  case / control parameters (controlPeriod, n_actions, ...)
      configs/sac.yaml      SAC hyperparameters (actor [8] tanh, critic [16,64,64],
                            buffer 2e7, 640 gradient steps, lr 5e-4)
      utils/export_actor.py exports the PyTorch actor to a TensorFlow SavedModel
                            (deterministic tanh(mu) only) for cppflow in OpenFOAM
      verify_export.py      Verification 1: PyTorch vs SavedModel, 100 random states
      verify_cpp.py         Verification 2: C++ actions in pimpleFoam vs PyTorch
      verify_model.py       deployment fingerprint check at (u',v') = (0.5,-0.3)
      verify_all.py         no-contamination check across case directories

    openfoam_case/        OpenFOAM case template (mesh generated by blockMesh)
      0.orig/ constant/ system/   BCs incl. channelDRLControl on the wall,
                            fvSchemes (backward, Gauss linear), fvSolution
                            (nOuterCorrectors 2, nCorrectors 3), function objects
      Allrun.*              run scripts

    policy/batch_102.zip  the trained SAC checkpoint used for all thesis results
                          (training from uncontrolled field t = 9500 s)

    analysis/             physical-analysis scripts (thesis Chapter 4)
      profiles_settled.py         turbulence statistics, 3 cases
      quadrant_3way.py            quadrant analysis at y+ ~ 15
      joint_pdf_3panel_heat.py    joint PDF of sensed (u'+, v'+)
      policy_map_sonoda_settled.py  network policy map (opposition vs learned)
      policy_map_recorded.py      policy map from recorded states/actions
      streaks_vs_actuation_v3.py  streaks vs applied wall velocity
      power_budget_deter.py       actuation power budget

    verification/         solver verification scripts
      plot_pimple_sensitivity.py  corrector study vs Kim–Moin–Moser DNS
      compare_residuals.py        pressure residuals, CN vs backward

## Reward, state, action
State per actuator: (u'+, v'+) at y+ ~ 15, u'+ = (u - 0.09085)/u_tau, v'+ = v/u_tau,
u_tau = 0.00844. Action: wall-normal velocity a*u_tau, mean over the 1064
actuators removed each step (zero net mass flux). Reward, shared by all agents:
r = 1 - Cf/Cf_unc with Cf the wall-averaged skin friction at the control step.

## Running
1. Compile `channelDRLControl` (supervisor's library) and cppflow/TensorFlow C API.
2. `cd openfoam_case && ./Allrun.pre` (blockMesh, decomposePar).
3. `python framework/training.py` with the two YAML configs.
4. Evaluation: set `deterministic: true` in `channel.yaml`, load a checkpoint,
   export with `utils/export_actor.py`, run one episode; analyse with `analysis/`.

Data paths inside the analysis scripts point to the NSC Sigma project
`/proj/liu2/msc_thesis_aditya/`; adjust to your own copies of the runs.
